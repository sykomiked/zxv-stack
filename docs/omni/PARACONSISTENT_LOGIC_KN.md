# ಪ್ಯಾರಾಕಾನ್ಸಿಸ್ಟೆಂಟ್ ತರ್ಕ: ಸಂಪೂರ್ಣ ಪರಿಚಯ

**ಕನ್ನಡ** · ZXV — ಪ್ಯಾರಾಕಾನ್ಸಿಸ್ಟೆಂಟ್ ತರ್ಕ · ಸ್ಟೇಟ್ ಮೆಷಿನ್ · ಬಗೆಹರಿಸುವಿಕೆ


ಪ್ರತಿಯೊಂದು ವಿತರಣಾ ವ್ಯವಸ್ಥೆಯು ಒಂದೇ ಗೋಡೆಯನ್ನು ಎದುರಿಸುತ್ತದೆ: ಎರಡು ಮೂಲಗಳು ಸತ್ಯದ ಬಗ್ಗೆ ಭಿನ್ನಾಭಿಪ್ರಾಯ ಹೊಂದಿವೆ, ವ್ಯವಸ್ಥೆಯು ನಿರ್ಧರಿಸಬೇಕು. ಶಾಸ್ತ್ರೀಯ ದ್ವಿಮೌಲ್ಯ ತರ್ಕವು ವಿರೋಧಾಭಾಸದಲ್ಲಿ ಸ್ಫೋಟ ತತ್ವವನ್ನು ಪ್ರಚೋದಿಸುತ್ತದೆ. ಪ್ಯಾರಾಕಾನ್ಸಿಸ್ಟೆಂಟ್ ತರ್ಕವು ಬೇರೆ ಉತ್ತರ ನೀಡುತ್ತದೆ: ವಿರೋಧಾಭಾಸವನ್ನು ಮಾಹಿತಿ ಎಂದು ಪರಿಗಣಿಸಿ.

---

## 1. ಶಾಸ್ತ್ರೀಯ ತರ್ಕ ಪರಿಹರಿಸಲಾಗದ ಸಮಸ್ಯೆ
ಹೊರಗಿಡಲಾದ ಮಧ್ಯ ನಿಯಮ (P ಅಥವಾ not-P) ಪ್ರತಿಯೊಂದು ಪ್ರತಿಪಾದನೆಯು ನಿಜ ಅಥವಾ ಸುಳ್ಳು ಎಂದು ಭಾವಿಸುತ್ತದೆ. ಆದರೆ ವಿತರಣಾ ಪರಿಸರದಲ್ಲಿ P ಮತ್ತು not-P ಒಟ್ಟಿಗೆ ಬರಬಹುದು. ಶಾಸ್ತ್ರೀಯ ವ್ಯವಸ್ಥೆಗಳು ಭಯ, ಕೊನೆಯ-ಬರಹಗಾರ, ಅಡಚಣೆ ಅಥವಾ ಬಹುಮತದಿಂದ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತವೆ — ಪ್ರತಿಯೊಂದೂ ಮಾಹಿತಿಯನ್ನು ಕಳೆದುಕೊಳ್ಳುತ್ತದೆ.

---

## 2. ನಾಲ್ಕು ಮೌಲ್ಯಗಳು
ನಾಲ್ಕು-ಮೌಲ್ಯ ಸ್ಟೇಟ್ ಮೆಷಿನ್ TRUE, FALSE, NEITHER, BOTH ಅನ್ನು ಮೊದಲ ದರ್ಜೆಯ ಸ್ಥಿತಿಗಳಾಗಿ ಪರಿಗಣಿಸುತ್ತದೆ. BOTH ಎಂದರೆ ವಿರೋಧಾಭಾಸ ದಾಖಲಾಗಿ ಇಡಲಾಗಿದೆ — ಎಂದಿಗೂ ಬಲವಂತವಲ್ಲ, ಎಂದಿಗೂ ಅಳಿಸಲಾಗುವುದಿಲ್ಲ. ಇದು ಬೆಲ್ನಾಪ್ ತರ್ಕ, ವ್ಯವಸ್ಥೆ ಮೂಲವಾಗಿ.

---

## 3. ಸರಪಳಿ-meet ಬೀಜಗಣಿತ
ಸ್ಥಿತಿಗಳನ್ನು ಪೂರ್ಣ ಸರಪಳಿಯಲ್ಲಿ ಕ್ರಮಗೊಳಿಸಿ: FALSE < NEITHER < BOTH < TRUE. meet ಚಿಕ್ಕ ಶ್ರೇಣಿಯನ್ನು ನೀಡುತ್ತದೆ; join ದೊಡ್ಡದು. TRUE ತುದಿಯಲ್ಲಿರುವುದರಿಂದ, non-TRUE ಮೌಲ್ಯಗಳ ಯಾವುದೇ ಸಂಯೋಜನೆಯು TRUE ನೀಡಲಾರದು — ಬದಲಾಗದ್ದು ರಚನಾತ್ಮಕ.

---

## 4. ಬದಲಾಗದ್ದು
ಬಗೆಹರಿಸುವ ನಿಯಮವು ಶ್ರೇಣಿ ರಚನೆಯಿಂದ ಬರುತ್ತದೆ: TRUE ಮಾತ್ರ ಬಗೆಹರಿಸುತ್ತದೆ. ವಿರೋಧಾಭಾಸ (BOTH) ಇಟ್ಟು ದಾಖಲಿಸಲಾಗುತ್ತದೆ; ಒಪ್ಪಂದ (TRUE) ಮಾತ್ರ ಕ್ರಿಯೆಗೆ ಅಧಿಕಾರ ನೀಡುತ್ತದೆ. ಬೀಜಗಣಿತವು ಸ್ವಯಂ-ಸಮಾನ, ವಿನಿಮಯಶೀಲ, ಸಹಾಯಕ ಮತ್ತು ಹೀರುವಂಥದ್ದು — ಎಲ್ಲಾ 16 ಮತ್ತು 64 ಸಂಯೋಜನೆಗಳಲ್ಲಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ.

**TRUE ಮಾತ್ರ ಬಗೆಹರಿಸುತ್ತದೆ. TRUE+FALSE=BOTH — ವಿರೋಧಾಭಾಸಗಳನ್ನು ದಾಖಲಿಸಲಾಗುತ್ತದೆ, ಎಂದಿಗೂ ಬಲವಂತವಲ್ಲ.**

---

## 5. ತೀರ್ಮಾನ
ಪ್ಯಾರಾಕಾನ್ಸಿಸ್ಟೆಂಟ್ ತರ್ಕವು ಶಾಸ್ತ್ರೀಯ ವ್ಯವಸ್ಥೆಗಳು ನಿರಾಕರಿಸುವುದನ್ನು ಪರಿಹರಿಸುತ್ತದೆ: ಸತ್ಯ ವಿವಾದಾಸ್ಪದವಾದಾಗ ಏನು ಮಾಡಬೇಕು. ಉತ್ತರ: ವಿರೋಧಾಭಾಸವನ್ನು ಪುರಾವೆಯಾಗಿ ಇಟ್ಟು ನಿಜವಾದ ಒಪ್ಪಂದದ ಮೇಲೆ ಮಾತ್ರ ಬಗೆಹರಿಸಿ.

ವ್ಯವಸ್ಥೆ ತೆರೆದಿದೆ.
