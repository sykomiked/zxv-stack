# Використання розгортання ZXV на NEAR: повний посібник

**Українська** · ZXV — параконсистентна логіка · скінченний автомат · розрахунок


ZXV — жива реалізація параконсистентної логіки в мережі NEAR. Цей посібник пояснює, як читати, перевіряти та використовувати розгортання — без газу, без гаманця для читання.

---

## Адреси
Канонічна адреса — zedec.near, живий маршрутизуючий контракт. Вона вказує на протокол (мікроконтракт із 110 наборів), реєстр (136 можливостей) і шлюз (інваріант ядра).

---

## Як читати систему
Будь-який клієнт читає систему без газу через view-виклики. Універсальний інтерфейс навчає сам: ux_manifest повертає повну схему, ux_help відповідає на будь-яку тему.

---

## Як приєднатися
Новий учасник викликає mint_onboard: разовий грант 5000 одиниць, витратний на платформі, але не передаваний. Потім pool_enter дає доступ через пул ліквідності.

---

## Як перевірити
Інваріант перевіряється on-chain: conjoin повертає чотиризначний результат; is_settleable істинне лише для TRUE; verify_chain підтверджує ланцюг аудиту.
