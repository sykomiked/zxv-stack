# ZXV NEAR તૈનાતી વાપરવી: સંપૂર્ણ માર્ગદર્શિકા

**ગુજરાતી** · ZXV — પેરાકોન્સિસ્ટન્ટ તર્ક · સ્ટેટ મશીન · સમાધાન


ZXV NEAR નેટવર્ક પર પેરાકોન્સિસ્ટન્ટ તર્કનું જીવંત અમલીકરણ છે. આ માર્ગદર્શિકા તૈનાતી કેવી રીતે વાંચવી, ચકાસવી અને વાપરવી તે સમજાવે છે.

---

## સરનામાં
કેનોનિકલ સરનામું zedec.near, જીવંત રૂટીંગ કરાર. તે પ્રોટોકોલ (110-કિટ માઇક્રો-કરાર), રજિસ્ટ્રી (136 ક્ષમતાઓ) અને ગેટ (કર્નલ અપરિવર્તનીય) તરફ નિર્દેશ કરે છે.

```

```

---

## સિસ્ટમ કેવી રીતે વાંચવી
કોઈપણ ક્લાયંટ view calls દ્વારા ગેસ-મુક્ત વાંચી શકે છે. સાર્વત્રિક ઈન્ટરફેસ સ્વयं શીખવે છે: ux_manifest સંપૂર્ણ સ્કીમા આપે છે, ux_help કોઈપણ વિષયનો જવાબ આપે છે.

---

## કેવી રીતે જોડાવું
નવો અભિનેતા mint_onboard બોલાવે છે: એક-વાર 5000-એકમ અનુદાન, પ્લેટફોર્મ પર ખર્ચી શકાય પણ ટ્રાન્સફર ન થાય. પછી pool_enter લિક્વિડિટી પૂલ દ્વારા પ્રવેશ આપે છે.

---

## કેવી રીતે ચકાસવું
અપરિવર્તનીય on-chain ચકાસી શકાય છે: conjoin ચાર-મૂલ્ય પરિણામ આપે છે; is_settleable ફક્ત TRUE માટે સાચું; verify_chain ઓડિટ સાંકળ પુષ્ટિ કરે છે.
