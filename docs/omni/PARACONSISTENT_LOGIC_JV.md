# Logika parakonsisten: pambuka lengkap

**Basa Jawa** · ZXV — logika parakonsisten · mesin negara · rampung


Saben sistem terdistribusi ngadhepi tembok sing padha: rong sumber ora sarujuk babagan bebener, sistem kudu mutusake. Logika klasik micu prinsip ledakan nalika kontradiksi. Logika parakonsisten mangsuli beda: anggap kontradiksi minangka informasi.

---

## 1. Masalah sing ora bisa ditanggulangi logika klasik
Hukum tengah sing dipunsi (P utawa ora-P) nganggep saben proposisi bener utawa salah. Nanging ing lingkungan terdistribusi, partisi lan telat nggawe P lan ora-P teka bebarengan. Sistem klasik mangsuli panik, panulis-pungkasan, buntu, utawa paksaan mayoritas — saben ilang informasi.

---

## 2. Papat nilai
Mesin negara papat nilai nganggep TRUE, FALSE, NEITHER, BOTH minangka negara kelas siji. BOTH tegese kontradiksi dicathet lan ditahan — ora nate dipeksa, ora nate dibusak. Iki logika Belnap sing diadaptasi minangka primitif.

---

## 3. Aljabar meet rantai
Urutake negara ing rantai lengkap: FALSE < NEITHER < BOTH < TRUE. meet menehi pangkat cilik; join gedhe. Amarga TRUE ing pucuk, ora ana kombinasi nilai non-TRUE sing bisa ngasilake TRUE — invarian struktural.

---

## 4. Invarian
Aturan rampung asale saka struktur: mung TRUE sing ngrampungake. Kontradiksi (BOTH) ditahan lan dicathet; persetujuan (TRUE) mung menehi idin tumindak. Aljabar idempoten, komutatif, asosiatif, lan absorptif — kisi winates sing diverifikasi ing kabeh 16 lan 64 kombinasi.

**Mung TRUE sing ngrampungake. TRUE+FALSE=BOTH — kontradiksi dicathet, ora nate dipeksa.**

---

## 5. Kesimpulan
Logika parakonsisten ngrampungake apa sing ditolak sistem klasik: apa sing kudu ditindakake nalika bebener ditandingi. Jawaban: tahan kontradiksi minangka bukti lan rampung mung ing persetujuan sejati.

Sistem iki mbukak.
