# การใช้การติดตั้ง ZXV บน NEAR: คู่มือสมบูรณ์

**ไทย** · ZXV — ตรรกะพาราคอนซิสเทนต์ · เครื่องจักรสถานะ · การชำระ


ZXV คือการนำตรรกะพาราคอนซิสเทนต์ไปใช้จริงบนเครือข่าย NEAR คู่มือนี้อธิบายการอ่าน ตรวจสอบ และใช้การติดตั้ง — ไม่ใช้แก๊ส ไม่ต้องใช้กระเป๋าเงินเพื่ออ่าน

---

## ที่อยู่
ที่อยู่มาตรฐานคือ zedec.near สัญญาเส้นทางที่มีชีวิต ชี้ไปยังโปรโตคอล (ไมโครสัญญา 110 ชุด) ทะเบียน (136 ความสามารถ) และประตู (ค่าคงที่เคอร์เนล)

```

```

---

## วิธีอ่านระบบ
ไคลเอนต์ใดก็อ่านระบบโดยไม่ใช้แก๊สผ่าน view calls อินเทอร์เฟซสากลสอนตัวเอง: ux_manifest คืนสคีมาเต็ม ux_help ตอบทุกหัวข้อ

---

## วิธีเข้าร่วม
ผู้กระทำใหม่เรียก mint_onboard: เงินช่วยเหลือครั้งเดียว 5000 หน่วย ใช้จ่ายบนแพลตฟอร์มได้แต่โอนไม่ได้ แล้ว pool_enter ให้เข้าถึงผ่านกลุ่มสภาพคล่อง

---

## วิธีตรวจสอบ
ค่าคงที่ตรวจสอบได้ on-chain: conjoin คืนผลสี่ค่า is_settleable เป็นจริงเฉพาะ TRUE verify_chain ยืนยันโซ่ตรวจสอบ
