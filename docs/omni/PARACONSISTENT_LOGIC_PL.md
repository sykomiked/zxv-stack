# Logika parakonsystentna: pełne wprowadzenie

**Polski** · ZXV — logika parakonsystentna · maszyna stanów · rozliczenie


Każdy system rozproszony napotyka tę samą ścianę: dwa źródła nie zgadzają się co do prawdy, a system musi zdecydować. Logika klasyczna uruchamia zasadę eksplozji wobec sprzeczności. Logika parakonsystentna odpowiada inaczej: traktować sprzeczność jako informację.

---

## 1. Problem, którego logika klasyczna nie rozwiązuje
Prawo wyłączonego środka (P lub nie-P) zakłada, że każde zdanie jest prawdziwe lub fałszywe. Ale w środowisku rozproszonym P i nie-P mogą nadejść razem. Systemy klasyczne odpowiadają paniką, ostatnim pisarzem, zakleszczeniem lub przymusem większości — każde traci informację.

---

## 2. Cztery wartości
Maszyna stanów o czterech wartościach traktuje TRUE, FALSE, NEITHER i BOTH jako stany pierwszej klasy. BOTH oznacza, że sprzeczność jest zapisana i utrzymana — nigdy nie wymuszana, nigdy nie wymazana. To logika Belnapa zaadaptowana jako prymityw.

---

## 3. Algebra spotkania łańcuchowego
Uporządkuj stany na pełnym łańcuchu: FALSE < NEITHER < BOTH < TRUE. Spotkanie zwraca mniejszy rząd; join większy. Ponieważ TRUE jest na szczycie, żadna kombinacja wartości nie-TRUE nie może dać TRUE — niezmiennik jest strukturalny.

---

## 4. Niezmiennik
Reguła rozliczenia wynika ze struktury: tylko TRUE rozlicza. Sprzeczność (BOTH) jest utrzymana i zapisana; tylko zgoda (TRUE) autoryzuje działanie. Algebra jest idempotentna, przemienna, łączna i absorpcyjna — ograniczona krata zweryfikowana na wszystkich 16 i 64 kombinacjach.

**Tylko TRUE rozlicza. TRUE+FALSE=BOTH — sprzeczności są odnotowywane, nigdy nie wymuszane.**

---

## 5. Podsumowanie
Logika parakonsystentna rozwiązuje to, czego systemy klasyczne odmawiają: co robić, gdy prawda jest sporna. Odpowiedź: utrzymać sprzeczność jako dowód i rozliczać tylko na prawdziwej zgodzie.

System jest otwarty.
