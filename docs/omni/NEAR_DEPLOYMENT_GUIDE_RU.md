# Использование развёртывания ZXV на NEAR: полное руководство

**Русский** · ZXV — параконсистентная логика · конечный автомат · расчёт


ZXV — живая реализация параконсистентной логики в сети NEAR. Это руководство объясняет, как читать, проверять и использовать развёртывание — без газа, без кошелька для чтения.

---

## Как читать систему
Любой клиент читает систему без газа через view-вызовы. Универсальный интерфейс обучает сам: ux_manifest возвращает полную схему, ux_help отвечает на любую тему.

---

## Как присоединиться
Новый участник вызывает mint_onboard: разовый грант 5000 единиц, расходуемый на платформе, но не передаваемый. Затем pool_enter даёт доступ через пул ликвидности.

---

## Как проверить
Инвариант проверяем on-chain: conjoin возвращает четырёхзначный результат; is_settleable истинно только для TRUE; verify_chain подтверждает аудиторскую цепочку.
